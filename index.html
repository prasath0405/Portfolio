About Me

building web applications.

My Background

Writing code with real people in mind.

Before getting into web development, I graduated with a B.Sc. in Psychology. That background gave me a different way of looking at code: I always care about the person on the other side of the screen.

To me, good software isn't just about whether a server responds with 200 OK — it's about whether it feels intuitive, loads instantly, and doesn't make someone feel lost. If an interface is confusing or sluggish, the user doesn't care how clever the backend is.

In 2023, I joined SmartXoft as an intern. Within eight months, I earned a full-time role and started handling real client delivery. Today, I work across the whole stack: writing modular components in React, crafting REST APIs in Node.js and Express, designing schemas in MongoDB and MySQL, and deploying everything safely to AWS and Linux VPS.

When I'm not coding, I'm usually testing out new GSAP motion ideas, tweaking Lighthouse performance scores, or learning something new.
